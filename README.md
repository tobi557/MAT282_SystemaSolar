### Setup
To set up the project, clone the repository using `git clone <REPO-URL>`, navigate into the directory with `cd <PROJECT-FOLDER>`, and create the environment with `conda env create -f environment.yml`. 
Activate it via `conda activate orbit` and execute the simulation with `python simulation.py` (or open the folder in VS Code, select the `orbit` environment via `Ctrl + Shift + P` -> `Python: Select Interpreter`, and run the script). 

If packages are added later, update your environment using `conda env update --file environment.yml --prune`.

### Configuración
Para configurar el proyecto, clona el repositorio con `git clone <REPO-URL>`, entra a la carpeta con `cd <CARPETA-DEL-PROYECTO>` y crea el entorno ejecutando `conda env create -f environment.yml`. 
Luego actívalo mediante `conda activate orbit` y corre la simulación usando `python simulation.py` (o abre la carpeta en VS Code, selecciona el intérprete `orbit` con `Ctrl + Shift + P` -> `Python: Select Interpreter` y ejecuta el script). 

Si se agregan paquetes más adelante, actualiza tu entorno con `conda env update --file environment.yml --prune`.
